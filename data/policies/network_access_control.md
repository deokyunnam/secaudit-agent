# 네트워크 접근 통제 및 방화벽 운영 기준 (교육용 가상 문서)

- 문서 번호: SEC-NET-004
- 관리 부서: 네트워크보안파트
- 최종 개정: 2026-07-12
- 근거: ISMS-P 인증기준 (정보보호 및 개인정보보호 관리체계 인증)

## 제1조 (기본 원칙) — ISMS-P 2.6.1 네트워크 접근
1. 모든 서버 방화벽은 "기본 차단(Default Deny)" 정책을 적용하고, 필요한 포트만 허용한다.
2. 허용 포트는 CMDB에 등록된 목록과 일치해야 한다.
3. 운영(prd)·스테이징(stg)·개발(dev) 네트워크는 분리하여 운영한다.

## 제2조 (포트 허용 신청) — ISMS-P 2.6.1 네트워크 접근
1. 새 포트를 열려면 서버 담당 부서가 포트 허용 신청서를 제출해야 한다.
2. 신청서에는 포트 번호, 프로토콜, 접근 출발지(IP 대역), 사용 목적, 사용 기간을 적는다.
3. 네트워크보안파트 검토 후 승인되면 CMDB 허용 포트에 반영한다.
4. 임시 허용 포트는 최대 30일까지만 허용하며, 기간이 끝나면 자동으로 닫는다.

## 제3조 (외부 통신 통제) — ISMS-P 2.6.7 인터넷 접속 통제
1. 서버에서 인터넷으로 나가는 통신은 사내 프록시를 거쳐야 한다.
2. 승인되지 않은 외부 도메인으로의 데이터 전송은 차단 대상이다.
3. 프록시 로그에서 1MB 이상 외부 전송이 탐지되면 보안관제센터에 자동 통보한다.

## 제4조 (원격 접속) — ISMS-P 2.6.6 원격접근 통제
1. 리눅스 서버 원격 접속은 SSH(22)만 허용한다.
2. 윈도우 서버 원격 데스크톱(RDP, 3389)은 사내 VDI 대역에서만 접근을 허용한다.
3. 외부에서 사내 서버로의 직접 원격 접속은 금지한다.

## 제5조 (차단 조치) — ISMS-P 2.10.1 보안시스템 운영
1. 방화벽 정책 변경·차단 조치는 승인된 작업자가 관리자 승인 후 실행한다.
2. 운영 서버 포트 차단 시 서비스 담당 부서에 사전 통보하고, 차단 후 서비스 정상 여부를 확인한다.
3. 방화벽 정책은 반기 1회 검토하여 불필요한 허용 정책을 삭제한다.
